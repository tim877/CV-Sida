# Projekt: Kopiera Referensdesign med HTML & CSS

Detta projekt syftar till att återskapa en webbsida så lik referensbilderna som möjligt med hjälp av HTML och CSS. Målet är att exakt följa layout, färgschema och designprinciper från referensen.

## Översikt

Projektet består av en enkel, responsiv webbplats byggd med HTML5 och CSS3. Designen är noggrant utformad för att matcha de referensbilder som finns tillgängliga, med fokus på:

- Korrekt layout och struktur.
- Exakt användning av färger och typsnitt.
- Responsivitet för att säkerställa att sidan fungerar bra på olika enheter.

## Funktioner

- **Exakt layout:** Strukturen och placeringen av element följer referensbilderna.
- **Responsiv design:** Använder media queries för att anpassa layouten på olika skärmstorlekar.
- **Semantisk HTML:** Koden är strukturerad med semantiska element som `<header>`, `<main>`, `<section>` och `<footer>`.
- **Kommentarer i koden:** Både HTML- och CSS-filerna innehåller kommentarer som förklarar de viktigaste delarna.

## Teknologier

- **HTML5:** För strukturen av sidan.
- **CSS3:** För styling och layout (inklusive Flexbox och/eller CSS Grid för responsiv design).
